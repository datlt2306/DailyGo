# Lập trình Plugin WordPress (Plugin Development) chuyên sâu

Khóa học hướng dẫn lập trình các **chức năng mở rộng (Plugins)**, làm việc trực tiếp với database, lập trình blocks cho trình soạn thảo Gutenberg hiện đại, và phát triển các API RESTful riêng.

---
