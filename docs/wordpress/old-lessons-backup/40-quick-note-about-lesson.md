# Ghi Chú Nhanh Về Bài Học Tiếp Theo

## Các em các em lưu ý quan trọng

Trong bài học tiếp theo, khi thầy trò mình tạo loại bài đăng **Professor**, hãy nhớ thêm dòng code sau:

```php
'show_in_rest' => true
```

Dòng này rất quan trọng để đảm bảo loại bài đăng **Professor** hoạt động với trình chỉnh sửa khối (block editor) của WordPress.

## Tài liệu hỗ trợ

Bạn có thể tin tưởng rằng các tệp zip đi kèm với mỗi bài học đều được cập nhật đầy đủ và chính xác. Các em các em hãy kiểm tra chúng nếu cần tham khảo thêm.
