# Khóa học WordPress Developer (Theme & Plugin)

Chào mừng bạn đến với lộ trình phát triển WordPress chuyên nghiệp. Để đảm bảo khối lượng kiến thức đầy đủ và chuyên sâu, nội dung được chia làm **2 khóa học độc lập**:

---

## 🎨 1. Lập trình Giao diện WordPress (Theme Development)
Khóa học đi sâu vào lập trình giao diện (Theme) từ con số 0 dựa trên thiết kế tĩnh HTML/CSS, nắm vững cơ chế vòng lặp và tối ưu hóa theme.

- **Thời lượng**: 12 Buổi học
- **Nội dung nổi bật**: Cấu trúc Classic Theme, The Loop, CPT, WP_Query, ACF nâng cao, phân trang, bảo mật và hiệu năng.
- **Truy cập**: [👉 Xem Đề cương & Bài giảng Theme Development](./theme-development/index.md)

---

## 🔌 2. Lập trình Plugin WordPress (Plugin Development)
Khóa học chuyên sâu về lập trình tính năng mở rộng, hook hệ thống, kết nối cơ sở dữ liệu custom, lập trình khối Gutenberg và xây dựng REST API riêng.

- **Thời lượng**: 12 Buổi học
- **Nội dung nổi bật**: Action/Filter Hooks, Options/Transients API, Database thô ($wpdb), Admin Settings, Gutenberg Block, REST API và phát hành plugin.
- **Truy cập**: [👉 Xem Đề cương & Bài giảng Plugin Development](./plugin-development/index.md)
