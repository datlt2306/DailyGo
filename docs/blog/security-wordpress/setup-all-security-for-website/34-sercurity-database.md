# Cài đặt bảo mật cơ sở dữ liệu trong plugin "All In One Security": Từ Thầy Đạt

Chào các em, hôm nay thầy sẽ hướng dẫn các em cách sử dụng các cài đặt bảo mật cơ sở dữ liệu trong plugin **All In One Security**. Đây là nơi các em có thể thay đổi tiền tố cơ sở dữ liệu và sao lưu dữ liệu để tăng cường bảo mật. Nào, cùng bắt đầu nhé!

---

## Các cài đặt chính

### 1. **Database Prefix**
- **Lý do**: Tiền tố mặc định `wp_` dễ bị hacker khai thác.
- **Cách thực hiện**:
  1. Vào **Database Security** > **Database Prefix**.
  2. Sao lưu cơ sở dữ liệu trước khi thay đổi.
  3. Nhấn **Generate New Database Table Prefix** để tạo tiền tố ngẫu nhiên.
  4. Lưu cài đặt.

> **Lưu ý:** Đây là tính năng trung cấp, cần sao lưu trước khi thực hiện.

---

### 2. **Database Backup**
- **Chức năng**: Dẫn đến plugin **UpdraftPlus** để sao lưu cơ sở dữ liệu.
- **Cách thực hiện**:
  1. Vào **Database Security** > **Database Backup**.
  2. Sử dụng plugin UpdraftPlus để tạo bản sao lưu.

---

## Tóm tắt nhanh

- **Database Prefix**: Thay đổi tiền tố cơ sở dữ liệu để tăng cường bảo mật.
- **Database Backup**: Sử dụng plugin UpdraftPlus để sao lưu dữ liệu.
