# Cài đặt bảo mật file trong plugin "All In One Security": Từ Thầy Đạt

Chào các em, hôm nay thầy sẽ hướng dẫn các em cách sử dụng các cài đặt bảo mật file trong plugin **All In One Security**. Đây là nơi các em có thể quản lý quyền file, bảo vệ nội dung, và ngăn chặn việc sử dụng iframe trái phép. Nào, cùng bắt đầu nhé!

---

## Các cài đặt chính

### 1. **File Permissions**
- **Chức năng**: Kiểm tra và sửa quyền đọc/ghi của file và thư mục.
- **Cách thực hiện**:
  1. Vào **File Security** > **File Permissions**.
  2. Nhấn nút sửa quyền file theo khuyến nghị.
  3. Lưu cài đặt.

> **Lưu ý:** Tính năng này không hoạt động trên cài đặt local, chỉ hoạt động trên website trực tuyến.

---

### 2. **File Protection**
- **Chức năng**: 
  - Xóa các file mặc định không cần thiết (Readme, License, etc.).
  - Ngăn hotlinking (ngăn website khác sử dụng hình ảnh của bạn).
  - Vô hiệu hóa chỉnh sửa file PHP từ dashboard.
- **Cách thực hiện**:
  - Kích hoạt các tính năng và lưu cài đặt.

---

### 3. **Host System Logs**
- **Chức năng**: Xem nhật ký lỗi từ máy chủ.
- **Cách thực hiện**:
  1. Vào **File Security** > **Host System Logs**.
  2. Nhấn **View Latest System Logs** để xem nhật ký lỗi.

> **Lưu ý:** Nếu không có lỗi, nhật ký sẽ trống.

---

### 4. **Copy Protection**
- **Chức năng**: Ngăn người dùng sao chép nội dung từ website.
- **Cách thực hiện**:
  1. Vào **File Security** > **Copy Protection**.
  2. Kích hoạt tính năng và lưu cài đặt.

> **Lưu ý:** Tính năng này cũng vô hiệu hóa chuột phải, có thể gây bất tiện khi kiểm tra mã nguồn.

---

### 5. **iFrame Protection**
- **Chức năng**: Ngăn website khác nhúng nội dung của bạn bằng iframe.
- **Cách thực hiện**:
  1. Vào **File Security** > **iFrame Protection**.
  2. Kích hoạt tính năng và lưu cài đặt.

---

## Tóm tắt nhanh

- **File Permissions**: Kiểm tra và sửa quyền file.
- **File Protection**: Xóa file không cần thiết, ngăn hotlinking, và vô hiệu hóa chỉnh sửa PHP.
- **Host System Logs**: Xem nhật ký lỗi từ máy chủ.
- **Copy Protection**: Ngăn sao chép nội dung và vô hiệu hóa chuột phải.
- **iFrame Protection**: Ngăn nhúng nội dung bằng iframe.
