# Buổi 1 – Giới thiệu đề tài & chia nhóm

## 🎯 Mục tiêu học tập

-   Hiểu rõ đề tài "Hệ thống Quản lý Tour Du lịch"
-   Nắm được cấu trúc hệ thống và các module chính
-   Chia nhóm và phân công vai trò thành viên
-   Xác định module mà nhóm sẽ phụ trách

---

## 📋 Nội dung chính trên lớp

### 1. Giới thiệu đề tài (30 phút)

-   Giảng viên trình bày tổng quan về dự án
-   Giải thích hệ thống mô phỏng hoạt động của doanh nghiệp lữ hành
-   Nêu các chức năng cốt lõi của hệ thống

### 2. Cấu trúc hệ thống (20 phút)

Giảng viên giải thích các module gợi ý:

-   **Tour & Lịch trình**: Quản lý tour, điểm đến, lịch trình chi tiết
-   **Booking & Thanh toán**: Đặt tour, xử lý thanh toán, xác nhận đơn hàng
-   **Khách hàng & Đánh giá**: Quản lý thông tin khách hàng, đánh giá tour
-   **Hướng dẫn viên & Lịch làm việc**: Quản lý hướng dẫn viên, phân công lịch
-   **Quản trị hệ thống / Báo cáo**: Dashboard, thống kê doanh thu, quản lý user

### 3. Chia nhóm và phân vai (20 phút)

-   Chia nhóm (3–5 sinh viên/nhóm)
-   Phân vai trò:
    -   👨‍💼 **Leader**: Quản lý tiến độ, phân công công việc
    -   💻 **Developer**: Viết code, triển khai chức năng
    -   🧪 **Tester**: Kiểm thử, tìm lỗi
    -   📝 **Documenter**: Viết tài liệu, báo cáo

### 4. Thảo luận nhóm (20 phút)

-   Các nhóm thảo luận và chọn module phụ trách
-   Đặt câu hỏi với giảng viên về module đã chọn

---

## 🧠 Kiến thức trọng tâm / Giải thích

### Hệ thống Quản lý Tour Du lịch là gì?

Hệ thống website cho phép:

-   **Khách hàng**: Xem tour, đặt tour, thanh toán, đánh giá
-   **Nhân viên**: Quản lý tour, xử lý booking, theo dõi doanh thu
-   **Quản trị viên**: Quản lý toàn bộ hệ thống, phân quyền, báo cáo

### Công nghệ sử dụng

-   **Frontend**: HTML, CSS, JavaScript
-   **Backend**: PHP
-   **Database**: MySQL
-   **Version Control**: Git/GitHub

### Quy trình phát triển

1. Phân tích → 2. Viết Spec → 3. Thiết kế ERD → 4. Code → 5. Test → 6. Báo cáo

---

## 📘 Bài tập nhóm

### Project Proposal (1 trang A4)

Nộp file **Word hoặc PDF** với nội dung:

1. **Thông tin nhóm**

    - Tên nhóm
    - Danh sách thành viên (MSSV, Họ tên, Vai trò)

2. **Module phụ trách**

    - Tên module
    - Mô tả mục tiêu module (2–3 câu)

3. **Chức năng chính** (3–5 chức năng)

    - Liệt kê các chức năng sẽ triển khai
    - Ví dụ: "Thêm/sửa/xóa tour", "Tìm kiếm tour theo điểm đến"

4. **Phân công sơ bộ**
    - Ai làm phần nào (Frontend/Backend/Database/Tester)

### Deadline

Nộp trước buổi 2 (gửi qua email hoặc LMS)

## 💬 Gợi ý giảng viên

### ⏱ Thời lượng gợi ý

-   Giới thiệu: 30 phút
-   Cấu trúc hệ thống: 20 phút
-   Chia nhóm: 20 phút
-   Thảo luận: 20 phút
-   Tổng: ~90 phút

### 💡 Tips hướng dẫn

1. **Khuyến khích nhóm chọn module phù hợp**: Nếu nhóm có 3 người, không nên chọn module quá phức tạp
2. **Giải thích rõ vai trò**: Leader không chỉ là người phân công mà còn phải review code, theo dõi tiến độ
3. **Gợi ý module phổ biến**: Module Booking thường được chọn nhiều vì có nhiều logic nghiệp vụ thú vị
4. **Lưu ý về tích hợp**: Nhắc nhở các nhóm sẽ phải tích hợp module với nhau ở tuần 4

### 🔍 Câu hỏi thường gặp

-   **Q: "Nhóm em 5 người, có thể làm 2 module không?"**

    -   A: Có thể, nhưng cần đảm bảo tích hợp tốt và hoàn thành đúng deadline.

-   **Q: "Em chưa biết PHP nhiều, có làm được không?"**
    -   A: Có, giảng viên sẽ hướng dẫn trong quá trình làm. Quan trọng là tinh thần học hỏi và teamwork.
