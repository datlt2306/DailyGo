# Buổi 5 – Duyệt Spec & ERD

## 🎯 Mục tiêu học tập

- Nhận được feedback từ giảng viên về Spec và ERD
- Hiểu được các vấn đề cần chỉnh sửa
- Hoàn thiện Spec + ERD để sẵn sàng triển khai
- Chọn được giao diện HTML/CSS mẫu cho dự án

---

## 📋 Nội dung chính trên lớp

### 1. Giảng viên duyệt Spec & ERD từng nhóm (60 phút)

#### **Quy trình duyệt:**
1. Nhóm trình bày Spec và ERD (5 phút/nhóm)
2. Giảng viên review và đưa ra feedback (5 phút/nhóm)
3. Ghi nhận các vấn đề cần chỉnh sửa

#### **Các điểm giảng viên sẽ kiểm tra:**

**Spec:**
- ✅ Có đầy đủ 4 phần chính không?
- ✅ Chức năng có logic và đầy đủ không?
- ✅ Người dùng và quyền hạn có rõ ràng không?
- ✅ Luồng nghiệp vụ có hợp lý không?

**ERD:**
- ✅ Có đủ bảng cần thiết không?
- ✅ Quan hệ giữa các bảng có đúng không?
- ✅ Primary Key và Foreign Key có hợp lý không?
- ✅ Có thiếu hoặc thừa bảng không?

#### **Các lỗi thường gặp:**
- ❌ Spec thiếu chi tiết, quá chung chung
- ❌ ERD thiếu quan hệ, thiếu Foreign Key
- ❌ Quan hệ nhiều-nhiều chưa có bảng trung gian
- ❌ Chức năng trong Spec không khớp với ERD

### 2. Hướng dẫn chọn giao diện HTML/CSS mẫu (20 phút)

#### **Giới thiệu các nguồn template:**
- **Colorlib** (https://colorlib.com/): Nhiều template miễn phí
- **BootstrapMade** (https://bootstrapmade.com/): Template Bootstrap chất lượng
- **Start Bootstrap** (https://startbootstrap.com/): Template Bootstrap miễn phí
- **HTML5 UP** (https://html5up.net/): Template responsive đẹp

#### **Tiêu chí chọn template:**
1. **Phù hợp với module**: Template có layout tương tự chức năng module
2. **Responsive**: Hỗ trợ mobile, tablet
3. **Dễ chỉnh sửa**: Code rõ ràng, có comment
4. **Miễn phí hoặc có license phù hợp**

#### **Gợi ý template cho từng module:**
- **Module Tour**: Template tour du lịch, travel agency
- **Module Booking**: Template booking, e-commerce
- **Module Admin**: Template dashboard, admin panel
- **Module User**: Template profile, account management

### 3. Thảo luận và chỉnh sửa (10 phút)
- Các nhóm thảo luận với giảng viên về feedback
- Ghi chú các điểm cần chỉnh sửa

---

## 🧠 Kiến thức trọng tâm / Giải thích

### Tại sao cần duyệt Spec & ERD?

- ✅ **Phát hiện lỗi sớm**: Sửa ở giai đoạn thiết kế dễ hơn sửa khi đã code
- ✅ **Đảm bảo logic**: Spec và ERD phải khớp với nhau
- ✅ **Chuẩn bị tốt cho code**: Thiết kế tốt = code dễ dàng hơn
- ✅ **Tiết kiệm thời gian**: Tránh phải code lại nhiều lần

### Cách sử dụng template HTML/CSS

1. **Tải template về**
2. **Nghiên cứu cấu trúc**: HTML, CSS, JavaScript files
3. **Tùy chỉnh**: Thay đổi nội dung, màu sắc, layout
4. **Tích hợp với PHP**: Chuyển HTML tĩnh sang PHP động

### Lưu ý về bản quyền template

- ✅ Đọc kỹ license của template
- ✅ Nếu có yêu cầu credit, phải ghi rõ nguồn
- ✅ Không dùng template có bản quyền thương mại nếu không mua

## 📘 Bài tập nhóm

### Nộp Spec + ERD hoàn chỉnh + Link template

Nộp **3 file**:

1. **Spec module (đã chỉnh sửa)** (.docx hoặc .pdf)
   - Chỉnh sửa theo feedback của giảng viên
   - Đánh dấu các phần đã sửa (nếu có)

2. **ERD module (đã chỉnh sửa)** (.pdf hoặc ảnh)
   - Chỉnh sửa theo feedback của giảng viên
   - Kèm mô tả các bảng và quan hệ

3. **Link template đã chọn**
   - Gửi link template (Colorlib, BootstrapMade, v.v.)
   - Hoặc nộp file template đã tải về
   - Ghi chú: Template này sẽ dùng cho phần nào của module

### Format nộp

Tạo folder nộp với tên: `[Tên nhóm]_Spec_ERD_Template`

```
[Tên nhóm]_Spec_ERD_Template/
├── Spec_Module_[Tên module].pdf
├── ERD_Module_[Tên module].pdf
└── template_info.txt (hoặc .md)
```

**File template_info.txt:**
```
Template: [Tên template]
Link: [URL template]
Nguồn: [Colorlib/BootstrapMade/...]
Sử dụng cho: [Mô tả ngắn phần nào của module]
```

### 💡 Tips hướng dẫn
1. **Tạo checklist duyệt**: Chuẩn bị sẵn checklist để review nhanh và đầy đủ
2. **Ghi nhận feedback rõ ràng**: Yêu cầu các nhóm ghi chú feedback để chỉnh sửa
3. **Khuyến khích hỏi**: Nếu nhóm có thắc mắc, nên hỏi ngay trong buổi này
4. **Gợi ý template cụ thể**: Có thể đề xuất template phù hợp cho từng module

### 🔍 Câu hỏi thường gặp
- **Q: "Nếu Spec và ERD của nhóm em có vấn đề lớn, có phải làm lại không?"**
  - A: Tùy mức độ, nhưng thường chỉ cần chỉnh sửa. Nếu phải làm lại hoàn toàn, nên làm ngay để không ảnh hưởng tiến độ.

- **Q: "Nhóm em có thể tự thiết kế giao diện không dùng template không?"**
  - A: Có thể, nhưng cần đảm bảo responsive và đẹp. Dùng template sẽ tiết kiệm thời gian hơn.

- **Q: "Template có cần phải giống 100% với module không?"**
  - A: Không cần, chỉ cần phù hợp về layout. Có thể tùy chỉnh nhiều.
