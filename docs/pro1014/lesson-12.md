# Buổi 12 – Chuẩn bị demo hoàn chỉnh

> **Bài trước:** [Buổi 11: Theo dõi tiến độ lần 2](./lesson-11.md)  
> **Bài tiếp theo:** [Buổi 13: Hướng dẫn thuyết trình](./lesson-13.md)

## 🎯 Mục tiêu học tập

- Hoàn thiện slide thuyết trình
- Quay video demo module
- Chuẩn bị script thuyết trình
- Đảm bảo code chạy ổn định cho demo

---

## 📋 Nội dung chính trên lớp

### 1. Hướng dẫn làm slide thuyết trình (20 phút)

#### **Cấu trúc slide (10–15 slide):**

**Slide 1: Tiêu đề**
- Tên nhóm, Tên module
- Logo (nếu có)

**Slide 2: Giới thiệu nhóm**
- Danh sách thành viên và vai trò
- Module phụ trách

**Slide 3: Giới thiệu module**
- Mô tả module
- Mục tiêu module

**Slide 4–8: Demo chức năng**
- Mỗi slide = 1 chức năng chính
- Screenshot hoặc mô tả ngắn gọn

**Slide 9: Tính năng nâng cao**
- Liệt kê tính năng nâng cao
- Tích hợp với module khác

**Slide 10: Công nghệ sử dụng**
- PHP, MySQL, HTML, CSS, JavaScript
- Template, thư viện (nếu có)

**Slide 11: Kết quả đạt được**
- % hoàn thành
- Số commit, số tính năng

**Slide 12: Kết luận**
- Tổng kết
- Cảm ơn

#### **Tips làm slide:**
- ✅ Nội dung ngắn gọn, dễ đọc
- ✅ Dùng hình ảnh, screenshot
- ✅ Màu sắc nhất quán
- ✅ Font chữ lớn (≥24pt)
- ✅ Không quá nhiều chữ trên 1 slide

### 2. Hướng dẫn quay video demo (20 phút)

#### **Công cụ quay video:**
- **OBS Studio**: Miễn phí, chuyên nghiệp
- **Loom**: Dễ dùng, có thể quay màn hình + webcam
- **Screen Recorder** (Chrome extension): Đơn giản, nhanh

#### **Nội dung video demo (5–7 phút):**
1. **Giới thiệu (30 giây)**: Tên nhóm, module
2. **Demo chức năng chính (4–5 phút)**:
   - Chức năng 1 (1 phút)
   - Chức năng 2 (1 phút)
   - Chức năng 3 (1 phút)
   - Tính năng nâng cao (1–2 phút)
3. **Kết luận (30 giây)**: Tổng kết

#### **Tips quay video:**
- ✅ Test trước khi quay
- ✅ Chuẩn bị script nói
- ✅ Quay màn hình lớn (full HD)
- ✅ Nói rõ ràng, không quá nhanh
- ✅ Chỉnh sửa video nếu cần (cắt phần thừa)

### 3. Hướng dẫn viết script thuyết trình (20 phút)

#### **Script mẫu:**

```
[Slide 1 - Tiêu đề]
Xin chào thầy/cô và các bạn. Nhóm chúng em xin trình bày về Module [Tên module].

[Slide 2 - Giới thiệu nhóm]
Nhóm chúng em gồm [số] thành viên:
- [Tên 1] - [Vai trò]
- [Tên 2] - [Vai trò]
Module chúng em phụ trách là [Tên module].

[Slide 3 - Giới thiệu module]
Module [Tên] có chức năng [mô tả ngắn]. Mục tiêu của module là [mục tiêu].

[Slide 4 - Demo chức năng 1]
Chức năng đầu tiên là [Tên chức năng]. [Mô tả cách hoạt động].

[Slide 5-8 - Demo các chức năng khác]
[Tương tự]

[Slide 9 - Tính năng nâng cao]
Ngoài các chức năng cơ bản, module còn có tính năng nâng cao:
- [Tính năng 1]
- [Tính năng 2]
Module cũng đã tích hợp với [module khác].

[Slide 10 - Công nghệ]
Module sử dụng các công nghệ: PHP, MySQL, HTML, CSS, JavaScript.

[Slide 11 - Kết quả]
Module đã hoàn thành [X]% với [số] tính năng và [số] commit.

[Slide 12 - Kết luận]
Cảm ơn thầy/cô và các bạn đã lắng nghe. Nhóm chúng em xin hết.
```

#### **Tips viết script:**
- ✅ Viết ngắn gọn, dễ nhớ
- ✅ Tính thời gian (1 phút/slide)
- ✅ Tập nói trước
- ✅ Chuẩn bị trả lời câu hỏi

### 4. Kiểm tra code cho demo (20 phút)
- Đảm bảo code chạy ổn định
- Test lại các chức năng chính
- Fix lỗi nghiêm trọng (nếu có)
- Chuẩn bị dữ liệu mẫu

### 5. Thảo luận và hỏi đáp (10 phút)
- Các nhóm hỏi về slide, video, script
- Giảng viên hỗ trợ và gợi ý

## 📘 Bài tập nhóm

### Nộp video demo + slide nháp

#### **Yêu cầu:**

1. **Slide thuyết trình:**
   - File PowerPoint hoặc Google Slides
   - 10–15 slide
   - Nội dung đầy đủ theo cấu trúc đã hướng dẫn

2. **Video demo:**
   - Video 5–7 phút
   - Chất lượng tốt (full HD nếu có thể)
   - Upload lên YouTube (unlisted) hoặc Google Drive
   - Gửi link

3. **Script thuyết trình:**
   - File Word hoặc text
   - Script đầy đủ cho tất cả slide

4. **Cập nhật README.md:**
   - Thêm link video demo
   - Thêm link slide (nếu có thể)

### Format nộp

Tạo file `DEMO_PREPARATION.md` trong repo:

```markdown
# Chuẩn bị Demo

## Slide thuyết trình
- Link: [Link hoặc file đính kèm]
- Số slide: [X]

## Video demo
- Link: [Link YouTube hoặc Google Drive]
- Thời lượng: [X] phút

## Script thuyết trình
- File: [Tên file]

## Ghi chú
- [Ghi chú nếu có]
```

### Deadline
Nộp trước buổi 13 (gửi link hoặc file)

## 💬 Gợi ý giảng viên

### ⏱ Thời lượng gợi ý
- Hướng dẫn slide: 20 phút
- Hướng dẫn video: 20 phút
- Hướng dẫn script: 20 phút
- Kiểm tra code: 20 phút
- Thảo luận: 10 phút
- Tổng: ~90 phút

### 💡 Tips hướng dẫn
1. **Khuyến khích làm slide sớm**: Làm slide sớm để có thời gian chỉnh sửa
2. **Gợi ý công cụ**: Gợi ý công cụ quay video, làm slide
3. **Nhắc nhở về thời gian**: Video và thuyết trình không được quá dài
4. **Hỗ trợ nhóm yếu**: Nếu nhóm chưa có code chạy, cần hỗ trợ ngay

### 🔍 Câu hỏi thường gặp
- **Q: "Video demo có cần quay webcam không?"**
  - A: Không bắt buộc, nhưng nếu quay được thì tốt hơn (có thể dùng Loom).

- **Q: "Nếu code chưa chạy được, có thể làm slide/video không?"**
  - A: Có thể làm slide và video mô tả, nhưng tốt nhất là có code chạy được.

- **Q: "Slide có cần đẹp lắm không?"**
  - A: Không cần quá đẹp, nhưng cần gọn gàng, dễ đọc. Quan trọng là nội dung.
