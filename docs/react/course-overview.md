## 🎯 Mục tiêu học tập theo giai đoạn

### ✅ Sau Giai đoạn 1 (Tuần 1-3)

Học viên có thể:

-   Setup môi trường Vite + React
-   Hiểu JSX và Component structure
-   Sử dụng Props truyền dữ liệu
-   Quản lý State với useState
-   Xử lý Events
-   Conditional Rendering và List rendering
-   **Xây dựng**: Static website với React

### ✅ Sau Giai đoạn 2 (Tuần 4-5)

Học viên có thể:

-   Sử dụng useEffect cho side effects
-   Tạo Custom Hooks
-   Xây dựng Form hoàn chỉnh
-   Validate input data
-   Thực hiện Routing với React Router
-   **Xây dựng**: Multi-page application với routing

### ✅ Sau Giai đoạn 3 (Tuần 6-8)

Học viên có thể:

-   Kết nối API với Axios
-   Thực hiện CRUD operations
-   Quản lý state với Context API
-   Tổ chức code theo best practices
-   Styling với TailwindCSS
-   Xây dựng responsive UI
-   **Xây dựng**: Full-stack application hoàn chỉnh

## 🎓 Phương pháp giảng dạy

### 20% Lý thuyết / 80% Thực hành

**Lý thuyết (30 phút/buổi)**:

-   Giải thích khái niệm
-   Ví dụ minh họa ngắn
-   Demo live code

**Thực hành (90 phút/buổi)**:

-   Code demo cùng thầy
-   Lab tập cá nhân
-   Pair programming (buổi project)

### Quy trình học tập mỗi buổi:

1. **Warm-up** (10 phút): Review hoặc quiz
2. **Lý thuyết** (30 phút): Giải thích khái niệm mới
3. **Code demo** (20 phút): Ví dụ minh họa
4. **Lab tập** (60 phút): Thực hành với support
5. **Wrap-up** (10 phút): Tổng kết + Q&A
